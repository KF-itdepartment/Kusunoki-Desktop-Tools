# Pic Editor 第1段階仕様

## 対象範囲

この段階では、`pic-editor`内に独立した静的ブラウザアプリを提供します。兄弟プロジェクトは変更せず、Worker/API、サーバー側処理、外部画像ローダー、アップロード機能は持ちません。`public/index.html`は、将来の静的ホストやElectronのiframeから利用できる構成です。

## ドキュメントモデル

初期ドキュメントは1920 × 1080pxの透明キャンバスです。保存形式は次のとおりです。

```json
{
  "format": "kusunoki-picture-project",
  "version": 1,
  "document": { "width": 1920, "height": 1080, "objects": [] },
  "extension": {
    "background": { "color": "transparent", "fillScope": "full" },
    "layers": []
  }
}
```

`document.objects`にはFabricのオブジェクトJSONを保持します。各エディターオブジェクトには`kpicType`、`layerName`、ロック状態、メモリ上の安定したレイヤーIDがあります。画像は元の埋め込みdata URLを`kpicSrc`とFabricの`src`に保持します。読み込み時はPNG/JPEG/WebPのbase64 data URLだけを許可し、外部URLらしい値を再帰的に拒否します。キャンバスは1辺16,384px以下、100メガピクセル以下です。

## 編集動作

Fabric.js 7.4.0を使い、選択ハンドルから移動、拡大縮小、回転を行えます。ツールバーとパネルは、画像、文字、長方形、楕円、線、矢印の追加、単体・複数選択、複製、削除、表示／非表示、ロック、レイヤー名変更、前後移動、整列、等間隔、数値による位置・サイズ・角度指定、キーボード移動、Ctrl/Cmdショートカットに対応します。ドラッグやスライダーの一連の操作は1件のUndoとして記録し、履歴は最大50件です。

画像調整はグレースケール、明るさ、コントラスト、彩度、ぼかし、不透明度、左右・上下反転です。文字は内容、システムフォント、サイズ、太字、斜体、色、揃えを編集できます。

## トリミングとリサイズ

画像トリミングは専用モードになり、暗い外側表示、枠の移動、8方向のハンドルを提供します。適用時は枠をFabric画像の`cropX`、`cropY`、`width`、`height`へ変換し、表示枠のサイズを保ちます。キャンバストリミングは選択枠を基準にオブジェクトを移動し、キャンバスを枠のピクセルサイズに変更します。比率プリセットは枠の高さを幅から計算し、「自由」では制限しません。

キャンバスリサイズは次の3方式です。

- **引き伸ばす:** 新旧の幅・高さの比率を、オブジェクトの位置と拡大率へ個別に掛けます。
- **切り抜く:** 新しい矩形を覆うようにオブジェクトを一様に拡大縮小し、選択アンカーに合わせてずらします。キャンバス矩形の外側が見えない範囲になります。
- **余白を追加:** オブジェクトの拡大率を変えず、9種類のアンカーに応じた余白分だけ位置を移動します。「新しい余白のみ」では、既存背景をロックした背景矩形で残し、新しい4辺だけを塗ります。「背景全体」ではキャンバス背景色を全体へ適用します。

選択画像のリサイズも同じ3方式です。引き伸ばすと出力画像を正確な指定サイズへ伸縮し、切り抜くとアスペクト比を保って指定矩形へcoverしてから切り抜き、余白追加では元画像を伸ばさず指定サイズの新しい埋め込みPNGへ配置します。画像の角度、不透明度、反転、フィルター、位置、レイヤー名、重なり順は保持します。出力は非同期処理ですがUndoは1件です。

## 色、書き出し、表示倍率

背景色入力、RGB欄、透明チェックは同期します。スポイトはキャンバスの合成表示ピクセルをクリックして採取し、表示倍率を逆算します。Escで解除し、透明ピクセルは警告して別の場所を選べます。スポイト中は画像編集キャンバス以外を読みません。

ラスター書き出し時は一時的に表示倍率を1倍、ビューポート変換を単位行列にして描画するため、UIのズームは出力ピクセルへ影響しません。PNG/WebPは透明を保持します。JPEGは透明部分を指定背景色（初期値は白）へ置き換えます。書き出し元はキャンバスだけなので、画像メタデータはコピーされません。

## 保存と安全性

IndexedDBの1つのストアに下書きを1件保存します。変更から750ms後にデバウンス保存し、次回起動時は自動で読み込み、「自動保存した下書きを復元しました」と通知します。壊れた下書きは破棄して警告し、現在のキャンバスは置き換えません。「新規」は変更確認後に下書きを削除します。プロジェクト読み込みでは完全なオブジェクトツリーを検証・サニタイズしてからFabricへ渡します。レイヤー名やプロジェクト文字列をHTMLとして解釈しません。

静的ページは`connect-src 'none'`を含むCSPを宣言し、同一配下のスクリプト・スタイルだけを許可します。CDNや実行時の外部スクリプト、ネットワーク取得はありません。画像は1枚50MiB以下、最大30枚です。

## 検証

`npm test`はNode組み込みテストランナーで純粋ヘルパーと静的成果物を検証します。比率・寸法、3方式のリサイズ、9アンカー、余白矩形、RGB/HEX、ファイル名、画像31枚／50MiB超の拒否、レイヤー並べ替え、プロジェクト検証、履歴上限、日本語UIを対象にします。`npm run build`は固定依存をbundleし、公開ランタイムに外部script、外部dynamic import、ネットワーク取得が入った場合に失敗します。
